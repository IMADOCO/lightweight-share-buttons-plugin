A fast, private sharing block with native share, copy link, and nine social destinations.

== Description ==

Lightweight Share Buttons provides one focused Gutenberg block. It makes no external requests until a visitor chooses a destination, sets no cookies, collects no data, and includes no admin screen.

Features:

* Native Web Share menu when supported.
* Copy Link with Clipboard API and a browser fallback.
* Facebook, WhatsApp, LinkedIn, email, Telegram, X, Bluesky, Threads, and Reddit.
* Dynamic post, page, Query Loop, archive, and home URLs.
* Optional custom title, text, URL, and UTM parameters.
* Local SVG icons, keyboard support, and accessible status messages.
* Display, size, layout, alignment, shape, gap, wrapping, and color controls.

No accounts, API keys, tracking, telemetry, SDKs, or remote assets are used.

== Installation ==

1. Upload the plugin directory to `/wp-content/plugins/` or install its ZIP file.
2. Activate **Lightweight Share Buttons**.
3. Add the **Lightweight Share Buttons** block in the block editor.

== Frequently Asked Questions ==

= Does it track shares? =

No. The plugin stores and transmits no analytics data.

= Why is Native Share hidden? =

It appears only in browsers that support the Web Share API. Copy Link remains available.
